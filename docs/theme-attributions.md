# Community theme attribution

Cryptography Playground uses independently maintained developer color palettes as optional theme presets. These palettes originate in independent open-source developer-theme projects. The application builds its own interface and CSS variables; it does not copy upstream theme UI, fonts, icons, or branding.

| Theme | Maintainer | Original source | License |
| --- | --- | --- | --- |
| Catppuccin Latte/Mocha | Catppuccin | https://github.com/catppuccin/catppuccin | MIT |
| Dracula | Dracula Theme | https://github.com/dracula/dracula-theme | MIT |
| Gruvbox Light/Dark | morhetz | https://github.com/morhetz/gruvbox | MIT |
| Ayu Light/Mirage | ayu-theme | https://github.com/ayu-theme/ayu-colors | MIT |
| GitHub Light/Dark | GitHub Primer | https://github.com/primer/primitives | MIT |
| Everforest Light/Dark | sainnhe | https://github.com/sainnhe/everforest | MIT |

The project-original Notebook Paper and Notebook Ink themes are not third-party presets.

These are palette mappings adapted for this application. They do not represent the complete upstream token systems or every official variant. Retained notices and the upstream Gruvbox declaration are in [theme-license-notices.md](theme-license-notices.md). The application license remains an independent owner decision.

Appearance mode, theme, accent, background, foreground, and font are saved locally in the app's WebView storage. No remote theme or telemetry service is contacted.
